# Piedra for Revit — downloads

This repository hosts installer downloads for **Piedra for Revit** (beta). It contains no source code.

**Download the latest installer:**
https://github.com/GethubGod/piedra-releases/releases/latest/download/Piedra-for-Revit-Setup.exe

Installed copies check this repository's signed update feed and offer updates from inside the add-in (Update → Install update). Beta builds are currently unsigned, so Windows and Revit may warn before running them. Each release lists SHA-256 checksums in `SHA256SUMS.txt`.
